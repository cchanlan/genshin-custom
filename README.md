### Yunzai Genshin Plugin（个人定制版）

基于 [TRSS-Yunzai genshin 插件](https://gitee.com/TimeRainStarSky/Yunzai-genshin) 的定制版本。

上游的功能和指令**全部保留**，本仓库只是在此之上改了出图样式、补了几项查询。
下面的「与上游的不同」是这个仓库全部的改动，其余部分与上游一致。

同步上游：

```bash
git remote add upstream https://gitee.com/TimeRainStarSky/Yunzai-genshin
git fetch upstream && git merge upstream/main
```

## 与上游的不同

改动集中在 20 个文件，分五块。

### 1. #探险 整块重做

`#探险`（也叫 `#宝箱`、`#成就`、`#探索度`）的出图从浅色改成深色，布局也重排了。
除了样式，更主要的是**把需要跟版本维护的东西从代码里挪进了配置文件**，
游戏出新地区、新神瞳时不用改 JS。

数据总览：

- 活跃天数 / 深境螺旋 / 幻想真境剧诗 单独排在顶部，不带方块底，对齐米游社个人主页
- 其余项摊平成四列网格自动换行，项数增减不会破版（上游是写死的五列 × N 行）
- 神瞳改成自动识别：凡是接口里 `xxxculus_number` 形式的字段都会渲染。
  上游冰神瞳写死显示「待实装」，现在会正常出数字
- 宝箱获取率的等级配色取亮一档，深色底下对比度够

地图探险：

- 地区卡片带底图，优先用米游社的地区实景图（`resources/img/other/bg-地区名.jpg`），
  没有的退到 miao-plugin 的元素色主题图，都没有则用深蓝纯色兜底，不会破版
- 地区徽记缺失时回退到接口给的官方徽记，两者都没有就让文字填满卡片，不在左边留白
- 加了探索度进度条
- 声望改用接口的 `type` 字段判断（`type=Reputation` 且 `level>0`），
  上游是写死「蒙德璃月稻妻须弥枫丹」五个地区
- 供奉改成读 `offerings` 数组，上游是一串 `if name.includes(...)` 手写判断
- 补了七天神像（挪德卡莱叫新月神像）等级
- 子区域归并（渊下宫→稻妻、沉玉谷三个子区）从代码里的 `if id == 10` 挪到配置

新增的配置项都在 [defSet/role/index.yaml](defSet/role/index.yaml)：

| 配置项 | 作用 |
| --- | --- |
| `oculus` | 神瞳字段名 → 中文名，顺序即展示顺序。不登记也能显示，只是名字是英文 |
| `subArea` | 父地区 id → 子地区 id 列表，子区域并进父地区卡片 |
| `subAreaOnly` | 只展示子区域、不展示自身探索度的地区（如沉玉谷） |
| `areaElem` | 地区 → 元素色，决定卡片兜底配色 |
| `offeringAlias` | 供奉名简化（如「流明石之座」→「流明石」） |
| `offeringMax` | 每个地区最多显示几项供奉，默认 3。挪德卡莱有 8 个聚所，全列会撑爆卡片 |

同时把探索度的「分母」数据更新到了最新版本：成就 1676→1844、角色 113→121、
传送点 693→839、秘境 69→74、月神瞳 192→271，并补了冰神瞳 140。
这些数字接口不返回，只能跟着版本人工维护，改 yaml 即可。

### 2. 新增 #星铁角色

上游没有星铁的角色列表，这是新加的。

| 指令 | 说明 |
| --- | --- |
| `#星铁角色`、`#星铁角色列表` | 星穹铁道角色列表，含等级、星魂、行迹、光锥、遗器 |

实现在 [model/srRoleList.js](model/srRoleList.js)，模板 [role-list-sr.html](resources/html/player/role-list-sr.html)。
需要 miao-plugin（用它的 `#miao.models` 取角色数据和图片资源）。

### 3. 星铁接口补充

[model/mys/apiTool.js](model/mys/apiTool.js) 补了四个米游社接口，供上层功能调用：

- 虚构叙事 `challenge_story`
- 末日幻影 `challenge_boss`
- 异相仲裁 `challenge_peak`
- 活动日历 `get_act_calender`

混沌回忆的查询参数补上了 `need_all=true`，否则拿不到完整楼层数据。

### 4. #全部记录 改深色主题

[resources/html/gacha/](resources/html/gacha/) 下，`#全部记录` 的出图跟 `#角色记录` 统一成深色：

- 深色底 + 元素底图，数据卡改半透明黑 + 金色描边，数字金色
- 头图左侧加一层渐变，深色下 ID 和抽数看得清
- 集录池（type 500）标签补了配色（青绿 `#3FA89A`）。
  上游只定义了角色池红、武器池橙、常驻池紫，集录池没有底色
- 顺手修了两个模板变量错误：池名标签用的是 `{{type}}`（应为 `{{log.type}}`），
  五星历史时间用的是 `{{firstTime}}`（应为 `{{log.firstTime}}`）。
  这两处上游也有，导致标签不出颜色、时间不显示

### 5. 出图统一 webp

所有出图默认 `imgType: "webp"`。同画质下体积约为 jpeg 的三分之一，
失真反而更低（实测 58.3KB → 21.4KB）。调用方显式指定了格式的就听调用方的。

改动在 [model/base.js](model/base.js)，以及 `apps/calculator.js`、`apps/sevenSaints.js`、
`model/mysNews.js`、`model/payLogData.js` 里几处直接调 puppeteer 的地方。

## 安装

到 Yunzai 根目录下执行：

```bash
git clone https://gitcode.com/ccxhan/genshin-custom.git ./plugins/genshin/
```

> 目录名必须是 `genshin`，宿主和其它插件按这个路径加载。

`#星铁角色` 和 `#探险` 的部分配色依赖 [miao-plugin](https://gitee.com/yoimiya-kokomi/miao-plugin)，
建议一并安装。

宿主可选云崽 / 喵崽 / TRSS 崽 / JiuLi，本仓库在 JiuLi 上使用。
